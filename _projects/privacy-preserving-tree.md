## 项目概述

随机森林通过汇总多棵决策树的结果提升泛化能力，但在同态加密环境中，每棵树只能产生加密的叶路径分数，服务器既不能直接判断哪个叶节点有效，也不能在密文上执行离散的多数投票。已有方案通常需要客户端参与中间转换，或按完整二叉树逐层组织密文，导致交互轮次、槽位浪费和乘法深度随模型规模快速增长。

本项目提出 **P³RF（Packed Privacy-Preserving Random Forest）**：客户端仅上传一次加密特征，模型持有方在 CKKS 密文上完成节点比较、路径计算、类别对齐和森林聚合，再返回少量分组投票密文。客户端解密并舍入后即可恢复精确票数，全程只需一次上传—下载，不暴露原始输入，也不向服务器公开预测结果。

## 问题诊断与设计边界

单棵树经过 `SumPath` 后，正确叶节点的路径分数为 0，错误叶节点为 1 到树深度 D 之间的整数。真正的瓶颈不是树节点比较本身，而是如何在不知道有效叶位置的前提下，把大量离散路径分数转换成可累加的类别票数。

项目将系统拆成三个高内聚模块：`TECMP` 只负责密文节点比较，`SumPath` 只负责生成叶路径分数，新增的 **PIPS + PGA** 只负责从路径分数到森林票数的转换。模块之间以固定的密文槽位布局和有界整数分数为接口，因此可以独立替换比较协议、调节多项式精度或修改森林分组策略，而不需要重写整条推理链路。

核心约束包括：

- **非交互性：** 服务器推理期间不请求客户端完成布尔—算术转换或中间解密；
- **有界深度：** 聚合阶段的乘法深度不随树深度 D 线性增长；
- **可恢复票数：** 多项式逼近误差与 CKKS 噪声累积后仍落在舍入半径内；
- **可扩展打包：** 不同形状的非满二叉树仅占用实际节点和叶对应的槽位。

## 低阶路径指示多项式 $P_{PI}$

理想的路径指示函数应把分数 0 映射为缩放常数 N，把所有非零路径分数映射为 0，但这种离散函数无法由 CKKS 直接计算。P³RF 构造低阶多项式 $P_{PI}(x)$，满足 $P_{PI}(0) = N$，并让离散域中所有非零点的最大响应不超过 ε。

多项式系数、缩放常数 N 和误差上界 ε 通过线性规划联合求解。若每组包含 g 棵树、单个类别最多对应 Mmax 个叶节点、CKKS 经验噪声上界为 δ，则约束

$$ N ≥ 2 · g · M_{max} · (ε + δ) $$

保证每个类别的累计误差不超过 N/2，客户端对解密结果除以 N 并四舍五入即可恢复精确的组内票数。PIPS 参数选择算法会遍历候选阶数与缩放区间，寻找满足该约束的最低阶多项式，并据此动态确定安全分组大小。

在理论上，项目同时给出可行多项式的存在性证明和阶数上界：最低所需阶数不超过 D，并可利用移位 Chebyshev 多项式得到更紧的对数级上界。这一结果把“经验选择阶数”转化为具有明确正确性条件的参数配置过程。

## 打包分组聚合 PGA

PGA（Packed Group Aggregation）利用 CKKS 的 SIMD 槽位并行性，把来自多棵树、多个类别的路径结果汇总到少量密文中：

1. **槽位对齐：** 按“类别 × 类内叶偏移”将每棵树的叶路径分数旋转到统一位置；
2. **多项式求值：** 对对齐后的分数批量计算 PPI，使有效叶接近 N、无效叶接近 0；
3. **类别归约：** 使用明文掩码和旋转，把同一类别的所有叶响应压缩到固定类别槽位；
4. **分组累加：** 在误差预算允许的组大小内累加多棵树，得到 K 个分组投票密文。

这种布局按实际叶节点工作，不要求把每棵树填充成深度 D 的完整二叉树。整个协议的乘法深度被限制为 `⌈log₂ l⌉ + ⌈log₂ p⌉ + 1`，其中 l 为比较精度位数、p 为 PPI 阶数；通信量为 `O(m + K)` 个密文，其中 m 是特征维数。

## 正确性与隐私边界

在每组误差不超过 N/2 且明文投票具有至少 1 票严格多数间隔时，分组舍入可以确定性恢复每个类别的真实票数，所有分组相加后的预测与明文随机森林一致。真实模型偶尔会出现票数完全相同的情况，此时 CKKS 的微小残余噪声可能改变 `argmax` 的平局处理；这属于平局规则差异，而不是非平局样本上的同态计算错误。

安全分析采用半诚实两方模型和 CKKS 的 IND-CPA 假设：服务器只能看到公钥、评估密钥和加密输入，无法恢复客户端特征；客户端只获得每个分组的类别票数以及公开元参数，不接触树结构、阈值或中间节点结果。公开泄露范围被限定为比较位数、树数量、类别数、最大深度、每类最大叶数和 CKKS 配置等通用参数。

## 实验设计与结果

实验覆盖 Iris、Wine、Heart、Steel、Breast 和 Spam 六个 UCI 数据集，使用 OpenFHE 的 CKKS 实现，环维数为 16,384、安全级别为 128 bit。模型规模覆盖 50 至 300 棵树、深度 7 至 15，并在 6、13、26、53 bit 多种输入精度下与 HRF 和 Concrete-ML 对比。

| 评估维度 | 对照方案 | P³RF 结果 |
| --- | --- | ---: |
| 64 棵树的聚合阶段 | HRF | **7.1×–39.9×** 加速 |
| 64 棵树的端到端推理 | HRF | **1.2×–4.6×** 加速 |
| 不同树数、深度与精度的端到端推理 | Concrete-ML | **3.6×–70.7×** 加速 |
| 密文准确率 | 明文 P³RF / Concrete-ML | 非平局样本保持一致 |

PGA 将 HRF 中占总延迟 25%–60% 的树级聚合压缩到约 3%–7%。随着聚合开销被摊薄，性能瓶颈转移到密文节点比较阶段；实验还显示端到端延迟随树数量和树深度近似线性增长，为后续优化明确了方向。

## 项目贡献

- 提出非交互式 P³RF 协议，将隐私保护决策树评估扩展到可扩展的随机森林推理；
- 设计低阶路径指示多项式及 PIPS 参数选择算法，并证明分组票数恢复的正确性与多项式阶数上界；
- 设计 PGA 槽位布局和自适应森林分组机制，提高非满二叉树的 CKKS SIMD 利用率；
- 在六个公开数据集上完成精度、树规模、树深度和输入精度的系统实验，并对 HRF 与 Concrete-ML 进行端到端对比；
- 给出半诚实模型下的数据隐私、模型隐私、公开泄露和通信复杂度分析。
